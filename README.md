# Web Security Labs

A practical documentation of my web application security learning journey.

This repository contains notes, methodology, HTTP request analysis, and
lessons learned while working through intentionally vulnerable training
environments, primarily PortSwigger Web Security Academy.

## Topics

- IDOR / Access Control
- SQL Injection
- Authentication
- CSRF
- Burp Suite
- HTTP request and response analysis

## Learning Approach

For each vulnerability, I focus on understanding:

- How the vulnerability works
- Why the application becomes vulnerable
- How to identify it
- How to test it using Burp Suite
- Potential impact
- Appropriate mitigations
- Lessons learned from practical labs

## Tools

- Burp Suite
- Browser Developer Tools
- Linux
- Python
- PortSwigger Web Security Academy

## Disclaimer

All security testing documented in this repository was performed against
intentionally vulnerable training environments or systems for which testing
was authorized.
